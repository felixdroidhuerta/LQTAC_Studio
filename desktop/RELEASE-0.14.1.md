# LQTAC Studio 0.14.1

Descarga **LQTAC_Studio_0.14.1_Windows_x64_Portable.zip**, extrae la carpeta completa y abre **LQTAC Studio.exe** una vez. Después puedes abrir los proyectos .LQTS con doble clic.

Tamaño: 1.179.919.931 bytes. SHA-256: f5202600dc2f54145e858a90a14a095f17ebdc36307a8bf4b65c78443c132670. Se adjunta RELEASE-SHA256SUMS.txt.

- Corrige el error ERR_UNKNOWN_FILE_EXTENSION al abrir un proyecto desde el Explorador.
- Incluye un lanzador propio que entrega el documento al editor, incluso si Windows conserva un comando antiguo.
- Repara las asociaciones propias y las entradas de Abrir con, respetando otros programas elegidos por el usuario.
- Mantiene iconos, capturas, menús, FX, PNG/GIF y los dos motores de subtítulos offline de 0.14.0.

No muevas solo el EXE: electron.exe y resources forman parte del programa. Para Windows 10/11; el lanzador utiliza .NET Framework del sistema. Todo el procesamiento sigue funcionando sin conexión.

Esta versión sustituye a 0.14.0 como descarga recomendada. La publicación anterior se conserva sin modificar. Consulta FUNCIONAMIENTO.md para los límites de captura, ASR y compatibilidad VEGAS.
